# Code Signing Policy

Free code signing for Sakora Launcher is provided by [SignPath.io](https://signpath.io),
certificate by the [SignPath Foundation](https://signpath.org/).

- **Committers and reviewers:** the project maintainer(s).
- **Approvers:** the project maintainer(s).
- **Privacy policy:** This program does not collect or share personal data.
  The installer contacts the Sakora project server only to download the game
  client and to check its version.
